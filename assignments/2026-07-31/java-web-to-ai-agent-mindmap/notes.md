java web技能映射到Agent岗位，主要是保障agent的高可用、高并发、低消耗等，比如通过中间件等保证agent的高可用性。分布式微服务技术栈用于基础业务AI化升级、多agent协作等等。

RAG全链路：RAG是agent可以的一个工具，检索增强，用于构建并查询知识库文档等。具体链路是：构建知识库原始文件文档、向量化、存储向量库、查询压缩、查询路由、元数据过滤、重排序、最后交给LLM统一组织返回

Agent编排：通过A2A协议，用于横向agent间互相协作，是多agent协作场景的应用，常见的一种编排思路是编排（协调）agent来规划任务，research agent用来收集上下文和相关资料，coder agent用于实际操作根据需求编码，reviewer agent用于代码审查，评估安全性能和质量三个维度。

Function Calling：指的是函数/工具调用，具体面向的是“怎么调”的问题，用户提问时，业务代码暴露给大模型相关的函数/工具/方法及其描述，包括这个工具解决什么问题，参数如何等等，然后大模型来调用，实际运行还是在业务代码中，最后将调用结果交给LLM统一组织返回给用户。

MCP协议：用于agent纵向调用的工具集标准，来扩展agent能力，当用户发起query时，agent检测可用的mcp工具，然后依据mcp server的传输标准，将相关参数传给mcp server来执行。例如调用 数据库mcp执行创建修改查询等操作。
