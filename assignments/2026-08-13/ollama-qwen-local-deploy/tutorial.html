Phase 1 · RAG 刚需闭环

本地 Ollama 部署 Qwen 大模型 + Spring AI 接入本地推理

Phase 0 收尾任务 · 建立离线可跑的大模型推理环境
总预估时长：50 分钟（部署 20min / Spring AI 接入 20min / 验证 10min）

学习目标

完成本地 Ollama 部署 Qwen 大模型，并用 Spring AI 接入本地推理端点，实现离线可跑的 ChatClient 调用。理解本地模型与云端 API 的差异（延迟、量化、显存），为后续 RAG 项目提供零成本推理基座。

前置条件：Docker 已安装；至少 8GB 内存（推荐 16GB）；JDK 17+；Spring Boot 3.x 项目基础。

阶段一：安装 Ollama 并拉取 Qwen 模型

20 min

1.1 安装 Ollama

Linux/macOS 一键安装：

curl -fsSL https://ollama.com/install.sh | sh

验证安装：

ollama --version
ollama serve &

Ollama 默认在 http://localhost:11434 提供服务，兼容 OpenAI API 格式。

1.2 拉取 Qwen 模型

根据硬件选择合适的量化版本（首次使用推荐 7B）：

# 推荐：Qwen2.5 7B 量化版（约 4.7GB，8GB 显存可跑）
ollama pull qwen2.5:7b

# 显存有限可选 3B（约 1.9GB）
ollama pull qwen2.5:3b

# 验证模型可用
ollama run qwen2.5:7b "你好，请用一句话介绍你自己"
模型选择提示：Qwen2.5 系列提供 0.5B 到 72B 多种规格。7B-instruct 版本在 16GB 内存机器上 CPU 推理约 5-10 token/s，GPU 加速可达 30+ token/s。开发阶段用 7B 即可，不需要盲目追求大参数。

阶段二：Spring AI 接入 Ollama

20 min

2.1 添加依赖

Maven pom.xml：

<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-starter-model-ollama</artifactId>
</dependency>

<!-- Spring AI BOM -->
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.springframework.ai</groupId>
            <artifactId>spring-ai-bom</artifactId>
            <version>1.0.0</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

2.2 配置 application.yml

spring:
  ai:
    ollama:
      base-url: http://localhost:11434
      chat:
        options:
          model: qwen2.5:7b
          temperature: 0.7
          num-ctx: 4096

2.3 编写 ChatClient Controller

@RestController
@RequestMapping("/api/chat")
public class LocalChatController {

    private final ChatClient chatClient;

    public LocalChatController(ChatClient.Builder builder) {
        this.chatClient = builder
                .defaultSystem("你是一个Java技术助手，回答简洁专业。")
                .build();
    }

    @GetMapping("/ask")
    public String ask(@RequestParam String question) {
        return chatClient.prompt()
                .user(question)
                .call()
                .content();
    }

    @GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public Flux<String> stream(@RequestParam String question) {
        return chatClient.prompt()
                .user(question)
                .stream()
                .content();
    }
}

2.4 验证调用

curl "http://localhost:8080/api/chat/ask?question=什么是RAG"

阶段三：关键理解与验收

10 min

3.1 本地模型 vs 云端 API

维度本地 Ollama云端 API（OpenAI/通义）
成本免费（电费）按 Token 计费
延迟较高（CPU 推理）低且稳定
数据安全完全离线数据外传
模型质量7B 够用，复杂推理弱GPT-4/通义Max 强
适用场景开发测试、敏感数据生产环境、高质量需求

3.2 验收标准

  • ollama list 能看到 qwen2.5:7b 模型
  • Spring Boot 启动无报错，/api/chat/ask 接口返回中文回答
  • 能口述本地模型与云端 API 的 3 个核心差异
  • 记录"为什么开发阶段选本地模型"到技术决策日志
