Spring AI 可观测性实战：Micrometer + Actuator 指标监控与 Token 用量追踪

Phase 0 收尾任务 · 为生产级 RAG 项目建立监控基座
总预估时长：55 分钟（依赖配置 15min / 指标验证 20min / Token 追踪 20min）

学习目标

掌握 Spring AI 的可观测性体系，使用 Micrometer + Actuator 暴露 ChatClient 调用指标（耗时、Token 用量、错误率），理解 LLM 应用监控与传统 Web 监控的差异。为后续 RAG 生产项目的成本控制和性能优化打基础。

前置条件：已有可运行的 Spring AI ChatClient 项目（OpenAI 或 Ollama 均可）；JDK 17+；了解 Spring Boot Actuator 基本概念。

阶段一：引入 Actuator 与 Micrometer

15 min

1.1 添加依赖

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-tracing-bridge-otel</artifactId>
</dependency>

1.2 暴露 Prometheus 端点

management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics,prometheus
  endpoint:
    metrics:
      enabled: true
  metrics:
    tags:
      application: spring-ai-rag-demo

启动后访问 http://localhost:8080/actuator/metrics 查看可用指标列表。

阶段二：验证 Spring AI 自动埋点指标

20 min

2.1 核心指标说明

Spring AI 自动注册以下 Micrometer 指标（无需手写代码）：

指标名类型说明
gen_ai.client.operation.durationTimerAI 调用耗时
gen_ai.client.token.usageDistributionSummaryToken 用量分布
gen_ai.server.request.durationTimer服务端响应时间

2.2 查看具体指标

# 查看 Token 用量
curl http://localhost:8080/actuator/metrics/gen_ai.client.token.usage

# 查看调用耗时（分位数）
curl "http://localhost:8080/actuator/metrics/gen_ai.client.operation.duration?tag=percentile&percentile=0.95"

2.3 低基数 vs 高基数标签

Spring AI 将标签分为两类：

  • 低基数标签（默认导出）：gen_ai.operation.name（chat/embed）、gen_ai.provider（openai/ollama）、error。可安全用于 Prometheus。
  • 高基数标签（需手动开启）：gen_ai.request.model、gen_ai.response.model、gen_ai.client.token.usage 的 type 维度（input/output）。开启方式：
management.observations.annotations.enabled=true
spring.ai.chat.observations.log-prompt=true
spring.ai.chat.observations.log-completion=true
注意：prompt/completion 日志可能包含敏感数据，生产环境需评估是否开启。建议仅在调试阶段临时启用。

阶段三：自定义 Token 用量追踪

20 min

3.1 通过 Advisor 拦截 Usage

Spring AI 的 ChatResponse 中携带 Token 使用信息。通过自定义 Advisor 可持久化记录：

@Component
public class TokenUsageAdvisor implements CallAroundAdvisor, StreamAroundAdvisor {

    private static final Logger log = LoggerFactory.getLogger(TokenUsageAdvisor.class);
    private final MeterRegistry meterRegistry;

    public TokenUsageAdvisor(MeterRegistry meterRegistry) {
        this.meterRegistry = meterRegistry;
    }

    @Override
    public String getName() { return "TokenUsageAdvisor"; }

    @Override
    public int getOrder() { return 0; }

    @Override
    public AdvisedResponse aroundCall(AdvisedRequest request, CallAroundAdvisorChain chain) {
        AdvisedResponse response = chain.next();
        ChatResponse chatResponse = response.response();
        if (chatResponse != null && chatResponse.getMetadata() != null) {
            Usage usage = chatResponse.getMetadata().getUsage();
            if (usage != null) {
                log.info("Token usage - prompt: {}, completion: {}, total: {}",
                    usage.getPromptTokens(), usage.getCompletionTokens(), usage.getTotalTokens());
                meterRegistry.counter("llm.tokens.total",
                        "type", "prompt").increment(usage.getPromptTokens());
                meterRegistry.counter("llm.tokens.total",
                        "type", "completion").increment(usage.getCompletionTokens());
            }
        }
        return response;
    }

    @Override
    public Flux<AdvisedResponse> aroundStream(AdvisedRequest request, StreamAroundAdvisorChain chain) {
        // 流式场景：在 doFinally 中汇总
        return chain.next().doFinally(signal -> {
            // 流式 usage 通常在最后一个 chunk 中
        });
    }
}

3.2 注册 Advisor

@Bean
public ChatClient chatClient(ChatClient.Builder builder, TokenUsageAdvisor tokenAdvisor) {
    return builder
            .defaultAdvisors(tokenAdvisor)
            .build();
}

3.3 对接 Prometheus + Grafana

在 prometheus.yml 中添加抓取配置：

scrape_configs:
  - job_name: 'spring-ai-app'
    metrics_path: '/actuator/prometheus'
    static_configs:
      - targets: ['host.docker.internal:8080']

Grafana 中建议配置三个面板：QPS、P95 延迟、Token 消耗速率（按 input/output 分线）。

验收标准

  • /actuator/metrics/gen_ai.client.operation.duration 返回非空数据
  • /actuator/metrics/gen_ai.client.token.usage 能看到 Token 计数
  • 调用一次 ChatClient 后，日志中打印了 promptTokens/completionTokens
  • 能口述低基数标签和高基数标签的区别，以及为什么不能把 prompt 内容作为 Prometheus 标签
  • 记录"选择哪些指标做告警"到技术决策日志
