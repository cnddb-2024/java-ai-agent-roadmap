# 任务完成总结

完成 RAG 核心概念学习，系统掌握了 Embedding、向量检索、Chunking、重排序四大环节的原理与作用。

核心收获：
1. **Embedding 原理**：离线阶段将资料分割成 chunk 切片，通过 embedding 模型向量化后存入向量数据库。本质是将文字转化成高维向量，检索时通过 query 与切片向量的余弦相似度判断语义相关性。
2. **向量检索**：将用户问题向量化后，与向量数据库内切片计算余弦相似度，越接近说明语义相关，检索出来。属于粗排阶段。
3. **重排序**：向量检索是粗排，可能检索出看似相关实则不需要的数据。重排序是精排，通过更慢但更精准的步骤（如 score 模型）筛选真正相关的切片。
4. **生成**：将筛选后的切片和处理后的用户问题一起发给 LLM，要求引用相关资料回答，不相关则不予回答。

RAG 是企业搭建 AI 知识库的最佳实践，核心原因有二：
- **知识热更新**：直接将新知识向量化入库即可，无需重新训练模型
- **错误可追溯**：通过 chunk 元数据可定位是哪部分知识出错，便于修正
