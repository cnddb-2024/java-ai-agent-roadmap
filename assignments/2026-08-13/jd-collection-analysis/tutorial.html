Phase 0 · 验收项

目标 JD 收集与刚需能力提取表

Phase 0 验收任务 · 用真实招聘数据驱动学习方向，避免闭门造车
总预估时长：50 分钟（搜索收集 20min / 提取分析 20min / 输出表格 10min）

学习目标

收集 10-15 个目标 Java AI Agent 岗位的真实 JD，按"硬性要求 / 加分项 / 工作内容 / 面试流程"四列提取刚需能力，形成个人学习路线的校准基线。用数据说话，避免"学了但市场不需要"的无效努力。

为什么要做这件事：Java 转 AI Agent 不是把所有 AI 技术都学一遍，而是精准匹配目标岗位的技能交集。JD 分析能帮你识别哪些是"每个岗位都要"的硬门槛，哪些是"有了更好"的加分项。

阶段一：搜索与收集目标 JD

20 min

1.1 搜索平台与关键词

在以下平台搜索，覆盖大厂、中厂和 AI 创业公司：

平台推荐搜索词
BOSS 直聘"Java AI Agent"、"Java 大模型应用"、"AI 应用开发 Java"
猎聘"Java RAG"、"Spring AI"、"LangChain4j"、"智能体 Java"
拉勾 / 智联"大模型 Java 开发"、"AIGC 后端"
LinkedIn"Java AI Engineer"、"LLM Application Developer"

1.2 筛选标准

  • 目标城市：你意向工作的城市（北上广深杭为主）
  • 薪资范围：25K-60K（中级到高级，匹配转型后定位）
  • 经验要求：3-5 年 Java 后端 + AI 方向
  • 收集数量：10-15 个 JD，至少覆盖 5 家不同公司

1.3 重点关注的公司类型

根据 2026 年招聘市场数据，以下类型公司在大量招 Java+AI 人才：

  • 大厂 AI 部门：腾讯（混元 Agent）、阿里（通义/客服 Agent）、字节（豆包应用层）
  • 金融科技：宁波银行、招行等金融 AI 部门（要求 Spring Cloud + RAG + Agent）
  • AI 原生公司：智谱、月之暗面、MiniMax 的应用工程岗
  • 传统企业 AI 转型：海康威视、运营商等（Java 底子 + Prompt/RAG）

阶段二：四列提取法

20 min

2.1 建立提取表格

每个 JD 按以下四列拆解（推荐用飞书多维表格或 Excel）：

列提取内容示例
硬性要求JD 中"必须/精通/熟悉"后的技能Java/Spring Boot、RAG、LangChain4j/Spring AI、向量数据库
加分项"优先/了解/有经验者优先"Python、MCP 协议、大模型微调、K8s
工作内容实际要做什么项目企业知识库 RAG、智能客服 Agent、文档问答系统
面试流程几轮面试、是否有笔试/系统设计3轮技术面 + 1轮HR，含 RAG 系统设计

阶段三：输出与校准

10 min

3.1 产出物

最终输出一份 Markdown 或表格文档，包含：

  1. JD 原始链接列表（10-15 个，标注公司/岗位/城市/薪资）
  2. 技能频次统计表（按 P0/P1/P2/P3 分级）
  3. 与当前路线图的差距分析：路线图已覆盖哪些 P0/P1 技能，哪些需要补充
  4. 面试重点提取：从 JD 描述中提炼出 5-8 个高频面试方向

3.2 与路线图对照

关键发现（基于 2026 年市场数据）：
  • Java+AI 岗位核心技能栈高度一致：Spring Boot/Cloud + Spring AI/LangChain4j + 向量数据库 + RAG + Agent
  • 2026 年新趋势：MCP 协议、Agent Skills、可观测性、AI 编程工具 已进入主流 JD
  • Python 是加分项而非硬门槛，约 53% 的岗位提到，但大多数标注"了解即可"
  • 面试重点从 CRUD 转向 RAG 全链路优化、Agent 长链路稳定性、系统设计 trade-off

3.3 验收标准

  • 收集至少 10 个真实 JD 链接（可访问、非重复）
  • 完成四列提取表，每个 JD 都有记录
  • 输出技能频次统计，标注 P0-P3 优先级
  • 写一段 200 字以内的"差距分析与学习校准"总结
  • 将文档提交到 assignments/2026-08-13/jd-collection-analysis/summary.md
