一、收集渠道与筛选标准

优先选择近 30 天发布、岗位名称含"AI 应用 / 大模型 / Java AI / Agent / RAG 后端"的职位。中英文 JD 都要收，比例建议 6:4（中文为主，英文看技能栈命名）。

渠道关键词备注
BOSS 直聘 / 拉勾 / 猎聘"AI 应用工程师"、"大模型后端"、"RAG"主战场，看描述真实度
LinkedIn"AI Engineer"、"LLM Application"、"Java + GenAI"看外企与远程岗技能栈
公司招聘官网字节、阿里、美团、蚂蚁、Shopee大厂 JD 描述更细
GitHub Jobs / V2EX / 电鸭"LLM"、"Agent"早期创业岗，技术栈新鲜
筛选硬标准
必须包含至少两项：(1) Java/Python/Go 之一作为主语言；(2) 提到 RAG 或向量数据库；(3) 提到 Agent / Function Calling / MCP；(4) 提到 Spring AI / LangChain / LangChain4j 任一框架。纯算法/模型训练岗排除，与本路线图定位不符。
